## 1. 検定が答えようとしている問い

A 案と B 案でボタンの色を変えて、クリック率を比べたとします。

| | 表示回数 | クリック |
|---|---|---|
| A 案 | 1000 | 100 (10.0%) |
| B 案 | 1000 | 120 (12.0%) |

**B のほうが 2 ポイント高い。B を採用すべきでしょうか。**

ここで立ち止まる必要があります。**まったく同じ 2 つの案でも、たまたま差は出る**からです。
公平なコインを 1000 回ずつ 2 セット投げても、表の数はぴったり同じにはなりません。

$$
\text{観測された差} = \underbrace{\text{本当の差}}_{\text{知りたい}} + \underbrace{\text{偶然のゆらぎ}}_{\text{邪魔}}
$$

仮説検定が答えるのは、この問いです。

> **「偶然のゆらぎだけで、これくらいの差が出ることはよくあるのか?」**

「よくある」なら差を主張できない。「めったにない」なら本物かもしれない。それだけの話です。

## 2. 帰無仮説と対立仮説

検定では、**主張したいことの逆**を仮定して話を始めます。

| 記号 | 名前 | 中身 | 立場 |
|---|---|---|---|
| $H_0$ | **帰無仮説** (null hypothesis) | 「差はない」$\mu_A = \mu_B$ | **否定したい**仮説 |
| $H_1$ | **対立仮説** (alternative hypothesis) | 「差がある」$\mu_A \ne \mu_B$ | 主張したい仮説 |

### なぜ回りくどいのか — 背理法だから

「差がある」を直接証明するのは困難です。差が $0.001$ でも「差がある」ことになってしまう。

そこで**背理法**を使います（[`04_discrete_math/02_proof_techniques.md`](../04_discrete_math/02_proof_techniques.md)）。

1. 「差はない」($H_0$) と**仮定する**
2. その仮定のもとで、観測されたデータがどれくらい珍しいか計算する
3. **あまりに珍しければ**、最初の仮定 $H_0$ がおかしかったと考える

「帰無」という名前は「**無に帰したい**（否定したい）仮説」から来ています。

> ⚠️ **$H_0$ を棄却できなかった = 「差がない」ことの証明ではありません。**
> 「差があるとは言えなかった」だけです。
> 裁判で「無罪」が「潔白の証明」ではなく「有罪と立証できなかった」であるのと同じ構造です。
> **証拠不十分と無実は違う。**

## 3. p 値 — 統計で最も誤解されている数字

$$
\boxed{p\text{ 値} = P(\text{今回以上に極端なデータが観測される} \mid H_0 \text{が正しい})}
$$

**条件付き確率であること**が決定的に重要です。$H_0$ を仮定したうえでの確率です。

### ❌ よくある誤解

| 誤解 | なぜ間違いか |
|---|---|
| 「$H_0$ が正しい確率が $p$」 | 逆。$p$ は $H_0$ を**前提とした**データの確率。$P(H_0 \mid D)$ ではなく $P(D \mid H_0)$ |
| 「$p = 0.03$ なら 97% の確率で差がある」 | 上と同じ取り違え |
| 「$p$ が小さいほど差が大きい」 | $p$ は**差の大きさ**ではない。$n$ が大きいだけでも小さくなる |
| 「$p > 0.05$ なら差はない」 | 「差があると言えなかった」だけ |

$P(D \mid H_0)$ と $P(H_0 \mid D)$ を取り違えるのは、
まさに [`04_bayes.md`](04_bayes.md) で扱った**条件付き確率のひっくり返し**の誤りです。

> 💡 例え話: 「日本人である確率」と「（東京にいるとして）日本人である確率」が違うように、
> 「$H_0$ が正しい確率」と「$H_0$ のもとでこのデータが出る確率」はまったく別物です。

### 有意水準 $\alpha$

あらかじめ「これより珍しければ $H_0$ を捨てる」という基準を決めておきます。慣習は $\alpha = 0.05$。

$$
p < \alpha \;\Longrightarrow\; H_0 \text{ を棄却（「有意差あり」）}
$$

> ⚠️ **0.05 に理論的な根拠はありません。** フィッシャーが便宜的に使った値が慣習化したものです。
> 分野によっては $0.01$、素粒子物理では $5\sigma$（約 $3 \times 10^{-7}$）が使われます。
> **$p = 0.049$ と $p = 0.051$ の間に、本質的な違いはありません。**

## 4. 2 種類の間違い

検定は「$H_0$ を棄却する / しない」の二択なので、間違い方も 2 通りあります。

| | $H_0$ が真（本当は差がない） | $H_0$ が偽（本当は差がある） |
|---|---|---|
| **棄却した** | ❌ **第一種の過誤** $\alpha$<br>（あわてんぼうの誤り） | ✅ 正解（検出力 $1-\beta$） |
| **棄却しない** | ✅ 正解 | ❌ **第二種の過誤** $\beta$<br>（ぼんやりの誤り） |

| 過誤 | 意味 | 医療検査でいうと | 実務での痛み |
|---|---|---|---|
| **第一種** $\alpha$ | 差がないのに「ある」と言う | 偽陽性 | 効果のない施策に投資する |
| **第二種** $\beta$ | 差があるのに見逃す | 偽陰性 | 有望な施策を捨てる |

### トレードオフ

$\alpha$ を小さくすれば（慎重になれば）、$\beta$ は大きくなります（見逃しが増える）。

**両方同時に小さくする唯一の方法は、$n$ を増やすことです。**

$$
\text{検出力 (power)} = 1 - \beta = \text{「本当に差があるとき、それを検出できる確率」}
$$

慣習的に検出力 $0.8$ 以上が目安とされます。
**調査を始める前に**「どれくらいの差を、どれくらいの確率で検出したいか」から必要な $n$ を逆算するのが
**サンプルサイズ設計 (power analysis)** です。

> 💡 **検定を「やってから」考えるのではなく、「やる前に」設計する。**
> データを取ってから「$n$ が足りなかった」と気づくのが、実務で最も多い失敗です。

## 5. t 検定 — 平均を比べる

最もよく使う検定です。3 種類あります。

| 種類 | 使う場面 | SciPy |
|---|---|---|
| **1 標本 t 検定** | 標本平均が基準値と違うか | `stats.ttest_1samp` |
| **対応のある t 検定** | 同じ対象の前後比較 | `stats.ttest_rel` |
| **独立 2 標本 t 検定** | 別々の 2 グループの比較 | `stats.ttest_ind` |

### 検定統計量の考え方

$$
t = \frac{\text{観測された差}}{\text{差の標準誤差}} = \frac{\bar{x} - \mu_0}{s/\sqrt{n}}
$$

**「差を、ばらつきで割る」**。これが検定統計量の基本形です。

同じ「平均が 2 違う」でも、データがきれいに揃っていれば大きな差、
バラバラなら誤差の範囲 — それを 1 つの数字にまとめています。

> 📌 分母は [`06_estimation.md`](06_estimation.md) で学んだ**標準誤差**です。
> $\sqrt{n}$ が入っているので、$n$ が大きいほど $t$ は大きくなり、有意になりやすくなります。
> **これが第 7 節の問題につながります。**

### Python 実装

```python
import numpy as np
from scipy import stats

rng = np.random.default_rng(42)

# 2 つのグループ (単位: 秒), shape: (30,) と (30,)
group_a: np.ndarray = rng.normal(loc=50.0, scale=5.0, size=30)
group_b: np.ndarray = rng.normal(loc=52.0, scale=5.0, size=30)   # 真の差は 2 秒

# 独立 2 標本 t 検定 (等分散を仮定しない Welch の t 検定)
t_stat, p_value = stats.ttest_ind(group_a, group_b, equal_var=False)

print(f'A の平均: {group_a.mean():.2f} 秒')
print(f'B の平均: {group_b.mean():.2f} 秒')
print(f't 統計量: {t_stat:.4f}')
print(f'p 値    : {p_value:.4f}')
print(f'判定    : {"有意差あり" if p_value < 0.05 else "有意差なし"} (α=0.05)')
```

> 💡 **`equal_var=False`（Welch の t 検定）を既定にするのが安全**です。
> 等分散を仮定する古典的な t 検定は、分散が違うと結果が歪みます。
> 「等分散かどうか事前に検定してから選ぶ」のは多重検定になるので、
> 最初から Welch を使うことが推奨されています。

## 6. その他の代表的な検定

| 検定 | 何を調べるか | SciPy |
|---|---|---|
| **カイ二乗検定** | カテゴリ変数の独立性（クロス集計表） | `stats.chi2_contingency` |
| **分散分析 (ANOVA)** | 3 群以上の平均の差 | `stats.f_oneway` |
| **相関の検定** | 相関係数が 0 と言えるか | `stats.pearsonr` |
| **Mann-Whitney U** | 正規性を仮定しない 2 群比較（ノンパラメトリック） | `stats.mannwhitneyu` |
| **Shapiro-Wilk** | 正規分布に従うか | `stats.shapiro` |

### 検定の選び方（大まかな地図）

```
比べたいものは何か?
├─ 平均 (量的データ)
│   ├─ 2 群 ────── t 検定 (Welch)
│   │              └─ 正規性が怪しい → Mann-Whitney U
│   └─ 3 群以上 ── ANOVA → 有意なら多重比較 (Tukey 等)
├─ 割合・度数 (カテゴリ) ── カイ二乗検定
└─ 関係の強さ ────────── 相関の検定 / 回帰分析
```

## 7. ⚠️ 統計的有意性 ≠ 実務的重要性

**このページで最も重要な節です。**

### $n$ を増やせば、どんな微小な差も「有意」になる

$t = \dfrac{\bar{x}_A - \bar{x}_B}{\text{SE}}$ の分母には $\sqrt{n}$ が入っています。
つまり **$n$ を大きくすれば分母が小さくなり、$t$ は無限に大きくできます**。

クリック率 **10.0% 対 10.1%**（差はわずか 0.1 ポイント）を固定して、$n$ だけを変えてみます。

| $n$（各群） | $z$ 統計量 | p 値 | 判定 |
|---|---|---|---|
| 1,000 | −0.074 | 0.941 | 有意差なし |
| 100,000 | −0.744 | 0.457 | 有意差なし |
| 1,000,000 | −2.352 | **0.019** | **有意差あり** |
| 10,000,000 | −7.437 | **< 0.001** | **有意差あり** |

**差はずっと 0.1 ポイントのまま**なのに、$n$ を増やすだけで「統計的に有意」になりました。

では、クリック率が 0.1% 違うことに、ビジネス上の意味はあるでしょうか。
施策の実装コストが 1000 万円なら、答えは「ない」かもしれません。

> **統計的有意性は「偶然ではなさそう」としか言っていない。**
> **「意味がある」かどうかは、統計ではなくドメイン知識が決める。**

### だから効果量と信頼区間を併記する

p 値だけを報告するのは不十分です。必ず次を添えます。

| 指標 | 何を言うか |
|---|---|
| **効果量 (effect size)** | 差の**大きさ**（例: Cohen's $d$ = 差 ÷ 標準偏差） |
| **信頼区間** | 差が**どの範囲**にありそうか |

「$p < 0.05$」より「**差は 2.0 秒（95% CI: 0.5 〜 3.5 秒）**」のほうが、はるかに情報量があります。

### p ハッキング

やってはいけないことも知っておいてください。

| 行為 | 何が問題か |
|---|---|
| **有意になるまでデータを追加** | 「そのうち当たる」。第一種の過誤が跳ね上がる |
| **多数の指標を検定して当たりを報告** | 20 個検定すれば 1 個は偶然 $p<0.05$ になる |
| **後から仮説を変える (HARKing)** | 結果を見てから仮説を作るのは検定ではない |
| **有意でない結果を報告しない** | 出版バイアス。世の中の「効果あり」が過大評価される |

**対策**: 分析計画を**事前に**決める（事前登録）、多重比較補正（Bonferroni 法など）、
そして「有意でなかった」も正直に報告すること。

> 📌 2010 年代、心理学や医学で**再現性の危機 (replication crisis)** が問題になりました。
> 有名な研究の多くが追試で再現できなかったのです。
> 原因の一つが、この p 値の誤用でした。
> 2016 年には米国統計学会が「**p 値だけで結論を出すな**」という異例の声明を出しています。

## 8. ML / AI への接続

| 場面 | 検定がどう効くか |
|---|---|
| **A/B テスト** | 施策の効果判定。サンプルサイズ設計と早期終了の罠 |
| **モデル比較** | 精度 92% と 93% の差は本物か。交差検証の各分割で検定 |
| **特徴量選択** | 回帰係数が 0 と言えるか（$H_0: \beta_j = 0$）。ただし多重比較に注意 |
| **データドリフト検出** | 訓練時と本番のデータ分布が変わっていないか（KS 検定など） |
| **公平性の検証** | 属性グループ間で予測性能に差がないか |

> ⚠️ **モデル比較での落とし穴**: ハイパーパラメータを 100 通り試して最良のものを報告すると、
> それは 100 回検定したのと同じです。**検証データへの過適合**が起きます。
> だから訓練 / 検証 / **テスト**の 3 分割が必要になります。
> テストデータは「最後に 1 回だけ」使うためのものです。

## 9. ハマりポイント

| ハマり | 何が起きるか | 対処 |
|---|---|---|
| p 値の誤解 | $P(H_0 \mid D)$ と取り違える | $p = P(D \mid H_0)$。条件付きの向きを確認 |
| 「有意差なし = 差がない」 | 存在しない結論を主張 | 「言えなかった」だけ。検出力不足かも |
| $n$ 大で微小差が有意 | 無意味な差を追いかける | 効果量と信頼区間を必ず併記 |
| 有意になるまでデータ追加 | 第一種の過誤が激増 | サンプルサイズを事前に決める |
| 多重比較 | 20 回やれば 1 回は当たる | Bonferroni 補正、FDR 制御 |
| 等分散の仮定 | 分散が違うと結果が歪む | `equal_var=False`（Welch）を既定に |
| 正規性の仮定 | 小標本で外れ値があると崩れる | ノンパラメトリック検定、ブートストラップ |
| 片側/両側の混同 | p 値が 2 倍違う | 事前に決める。基本は両側 |

## まとめ

| 概念 | 要点 |
|---|---|
| **帰無仮説 $H_0$** | 否定したい仮説。「差はない」 |
| **p 値** | $H_0$ のもとで、今回以上に極端な結果が出る確率 |
| **有意水準 $\alpha$** | 慣習は 0.05。理論的根拠はない |
| **第一種の過誤** | 差がないのに「ある」（あわてんぼう） |
| **第二種の過誤** | 差があるのに見逃す（ぼんやり） |
| **検出力 $1-\beta$** | 本当の差を検出できる確率。0.8 が目安 |
| **t 検定** | 「差 ÷ 標準誤差」。Welch を既定に |
| **効果量** | 差の**大きさ**。p 値とセットで報告 |

この章の核心:

> **p 値は「偶然にしては珍しい」としか言っていない。**
> **「意味のある差か」を決めるのは、統計ではなくあなたのドメイン知識である。**
