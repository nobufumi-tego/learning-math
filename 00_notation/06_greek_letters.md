# ギリシャ文字とよくある慣習

数学・物理・統計・MLで頻出。**「この文字はだいたいこういう意味」**という慣習を覚えると論文が読みやすくなる。

## ギリシャ文字一覧

| 小文字 | 大文字 | 読み方 | よくある意味（数学/ML/統計） |
|---|---|---|---|
| α | Α | alpha / アルファ | 学習率、有意水準、係数、**ベータ/ガンマ分布の形状パラメータ** |
| β | Β | beta / ベータ | 回帰係数、第二パラメータ、**ベータ分布の第2パラメータ / ガンマ分布の率** |
| γ | Γ | gamma / ガンマ | 割引率（強化学習）、**信用区間から外す確率**、ガンマ関数（大文字 Γ） |
| δ | Δ | delta / デルタ | 微小量、誤差、ディラックのδ関数 |
| ε | Ε | epsilon / イプシロン | 微小な正数、許容誤差、ノイズ項 |
| ζ | Ζ | zeta / ゼータ | ゼータ関数 |
| η | Η | eta / イータ | 学習率（αの代わり） |
| θ | Θ | theta / シータ | 角度、モデルパラメータ |
| ι | Ι | iota / イオタ | （ほぼ使わない） |
| κ | Κ | kappa / カッパ | 条件数、カーネルパラメータ、**事前分布の集中度** |
| λ | Λ | lambda / ラムダ | 固有値、正則化係数、ポアソン分布の率 |
| μ | Μ | mu / ミュー | 平均、期待値 |
| ν | Ν | nu / ニュー | 自由度、振動数 |
| ξ | Ξ | xi / クシー（グザイ） | 補助変数、確率変数 |
| ο | Ο | omicron / オミクロン | （ほぼ使わない） |
| π | Π | pi / パイ | 円周率、**確率分布（ベイズ）**、方策（強化学習）、総乗（大文字） |
| ρ | Ρ | rho / ロー | 相関係数、密度 |
| σ | Σ | sigma / シグマ | 標準偏差、活性化関数、総和（大文字） |
| τ | Τ | tau / タウ | 時定数、温度パラメータ、**事前/事後分散**（$\tau_0^2, \tau_n^2$） |
| υ | Υ | upsilon / ユプシロン | （ほぼ使わない） |
| φ | Φ | phi / ファイ | 特性関数、標準正規累積分布関数（大文字 Φ） |
| χ | Χ | chi / カイ | カイ二乗分布 |
| ψ | Ψ | psi / プサイ | 波動関数 |
| ω | Ω | omega / オメガ | 角速度、サンプル空間（大文字 Ω） |

## 機械学習で特によく出るもの（優先暗記）

| 文字 | 典型的な意味 | 例 |
|---|---|---|
| `θ` | モデルパラメータ | `θ = (w, b)` |
| `α`, `η` | 学習率 | `θ ← θ − η ∇L(θ)` |
| `λ` | 正則化係数 | `L + λ\|\|w\|\|²` |
| `μ` | 平均 | 正規分布 N(μ, σ²) |
| `σ` | 標準偏差 | 正規分布 N(μ, σ²) |
| `ε` | 微小量 / ノイズ | `y = f(x) + ε` |
| `Σ` | 共分散行列（大文字） | `N(μ, Σ)` |
| `∇` | 勾配（ナブラ） | `∇L(θ)` |

## Python での書き方

ギリシャ文字は変数名としては英語表記が一般的:

```python
# 数学: y = α x + β
def linear(x: float, alpha: float, beta: float) -> float:
    return alpha * x + beta

# 数学: θ ← θ − η ∇L
theta = theta - eta * grad_L
```

### Unicode 変数名

Python では Unicode 変数名が使えるが、可読性のため**通常は英語表記を推奨**:

```python
# OK だが推奨しない
α = 0.01
θ = np.zeros(10)

# 推奨
alpha = 0.01
theta = np.zeros(10)
```

## ナブラ ∇ と関連記号

| 記号 | 読み方 | 意味 |
|---|---|---|
| `∇f` | "nabla f" / 「ナブラ f」 | f の勾配（多変数の微分） |
| `∇·F` | "divergence" / 「発散」 | ベクトル場の発散 |
| `∇×F` | "curl" / 「回転」 | ベクトル場の回転 |
| `∇²` または `Δ` | "Laplacian" / 「ラプラシアン」 | 二階偏微分の和 |
| `∂` | "partial" / 「ラウンドディー」 | 偏微分 |

```python
import sympy as sp

x, y = sp.symbols("x y")
f = x**2 + 3 * y

# ∂f/∂x
print(sp.diff(f, x))  # 2*x

# ∇f = (∂f/∂x, ∂f/∂y)
grad = [sp.diff(f, v) for v in (x, y)]
print(grad)  # [2*x, 3]
```

## 大文字ギリシャ文字の特殊な使い方

| 記号 | 用途 |
|---|---|
| `Σ` | 総和（演算子） / 共分散行列 |
| `Π` | 総乗（演算子）/ 確率分布の積 |
| `Δ` | 差分 / ラプラシアン |
| `Γ` | **ガンマ関数**（階乗の実数への拡張。$\Gamma(n) = (n-1)!$） |
| `Φ` | 標準正規累積分布関数 |
| `Λ` | 対角行列 |
| `Ω` | 全体（サンプル空間） |

## ⚠️ 小文字 `π` は円周率とは限らない

これは**今いちばん引っかかりやすい多義性**です。ベイズ統計の論文では、$\pi(\cdot)$ は
**確率分布（密度関数）** を表す記号として使われます。

| 見た目 | 読み | 意味 |
|---|---|---|
| $\pi = 3.14159\ldots$ | パイ | **円周率**（引数がない） |
| $\pi(\theta)$ | パイ・シータ | **事前分布**（引数がある） |
| $\pi(\theta \mid x)$ | パイ・シータ・ギブン・エックス | **事後分布** |
| $\pi(a \mid s)$ | – | **方策**（強化学習。状態 $s$ での行動 $a$ の確率） |

**見分け方は「括弧の中に引数があるか」**。ただし同じ式に両方出ることもあります:

$$
f(x) = \frac{1}{\sqrt{2\pi}\,\sigma}\exp\!\left(-\frac{(x-\mu)^2}{2\sigma^2}\right)
$$

この $\sqrt{2\pi}$ の $\pi$ は円周率。一方 $\pi(\theta \mid x) \propto L(\theta;x)\pi(\theta)$ の $\pi$ は分布。

> 📌 なぜ $P$ ではなく $\pi$ を使うかというと、**「$\theta$ という未知パラメータに乗せた分布」**を
> 事象の確率 $P(A)$ と視覚的に区別したいから。
> → [`03_probability_statistics/08_bayesian_inference.md`](../03_probability_statistics/08_bayesian_inference.md)

## ハマりポイント

- 同じ文字でも分野で意味が違う（例: `σ` は統計だと標準偏差、ML だと活性化関数 sigmoid）
- 大文字 `Σ` は「演算子」と「共分散行列」を**文脈で判別**
- **小文字 `π` は「円周率」と「確率分布」の両方**。引数の有無で判断（上記参照）
- ε は「小さな正の数」の慣例だが、強化学習の「ε-greedy」では「探索確率」
- ν と v は字形が似ていて混同しがち
- 添字の `0` は「データを見る前」を表すことが多い（$\alpha_0, \mu_0, \tau_0^2$ ＝事前分布のパラメータ）
