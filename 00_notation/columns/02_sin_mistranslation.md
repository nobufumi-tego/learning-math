# コラム 02: `sin` は誤訳から生まれた — 「弓の弦」が「入り江」になるまでの 1000 年

> *三角関数の `sin` は、翻訳ミスでできた名前です。しかもそのまま 800 年使われています。*

## そもそも `sin` って何の略?

$\sin$、$\cos$、$\tan$。高校で散々使わされたのに、
**この 3 文字が何の略なのか**を教わった記憶がある人は、あまりいないはずです。

- $\tan$ = **tangent**（ラテン語 *tangere*「触れる」→ 接線）
- $\sec$ = **secant**（ラテン語 *secare*「切る」→ 割線）
- $\sin$ = **sine**（ラテン語 *sinus*「**入り江・湾・衣服のふところ**」）

... 入り江?

$\tan$ が「接線」、$\sec$ が「切る線」なのは、図を描けば納得できます。円に接する線、円を切る線ですから。

でも $\sin$ が「入り江」なのは、どう考えても意味が通りません。
三角形にも円にも、入り江など出てきません。

**実はこれ、翻訳ミスなのです。**

## 発端はインド — 「弓の弦」

三角関数の起源は、古代インドの天文学にさかのぼります。

5〜6 世紀の天文学者 **アーリヤバタ (Āryabhaṭa, 476-550頃)** らは、
天体の位置を計算するために、円の中の**線分の長さの表**を作りました。

彼らが着目したのは、円の**弦 (chord)** の半分の長さです。

```
        ....
     .        .
   .   ╱|      .
  .   ╱ |       .        ← 円弧を「弓」、
  .  ╱  | ← これが半弦     弦を「弓の弦」に見立てた
  . ╱   |       .
   ╱____|      .
     .        .
        ....
```

この「半分の弦」を、サンスクリット語でこう呼びました。

| サンスクリット | 意味 |
|---|---|
| **jyā**（ジヤー） | 弓の弦 |
| **ardha-jyā**（アルダ・ジヤー） | 半分の弦 |

弓を引いたときの、あの「弦」です。とても自然な命名です。

> 📌 現代の記号で書くと、半径 $r$ の円で中心角 $2\theta$ の弦の半分は $r\sin\theta$。
> つまりインドの数学者は、$\sin$ そのものを扱っていました。

## 伝言ゲームが始まる

インドの天文学は、8 世紀頃にアラビア世界へ伝わります。
バグダードの「知恵の館」を中心に、大量のサンスクリット文献がアラビア語へ翻訳されました。

このとき、**jyā** は意味を訳さず、**音をそのまま写す**形で取り込まれました。

$$
\text{jyā（弦）} \;\longrightarrow\; \text{アラビア語 } \textbf{jiba}
$$

ここまでは問題ありません。ところが、ここで**アラビア語の書記法**が事件を起こします。

### アラビア語は母音を書かない

アラビア語は通常、**子音だけを書いて母音を省略**します。
日本語で言えば「サクラ」を「skr」と書くようなものです。読み手が文脈で母音を補います。

つまり **jiba** は、書かれると:

$$
\textbf{jb} \quad (\text{جيب})
$$

そして数百年が過ぎました。

## 12 世紀、ラテン語への誤訳

12 世紀、今度はアラビア語の学術書がヨーロッパでラテン語に翻訳される時代が来ます。
スペインのトレドなどで、大規模な翻訳事業が行われました。

翻訳者たちは **jb** という綴りを見て、母音を補って読もうとしました。
そして、**jiba**（インド由来の外来語）ではなく、
アラビア語に実在する普通の単語 **jaib**（جيب）だと解釈してしまいます。

**jaib** の意味は — 「**懐（ふところ）、衣服の胸元のたるみ、湾、入り江**」。

そこで彼らは、その意味をラテン語に忠実に訳しました。

$$
\text{jaib（懐・湾）} \;\longrightarrow\; \text{ラテン語 } \textbf{sinus}
$$

ラテン語の **sinus** も「衣服のたるみ、ふところ、湾、入り江」を意味します。
訳語としては正確です。**元の単語の解釈さえ間違っていなければ。**

そして **sinus** が英語に入って **sine**、略して **sin** になりました。

### まとめると

| 段階 | 言語 | 語 | 意味 |
|---|---|---|---|
| 5世紀 | サンスクリット | jyā / ardha-jyā | **弓の弦** ✅ |
| 8世紀 | アラビア語（音訳） | jiba | （意味なし・音だけ） |
| — | アラビア語（表記） | jb | 母音が消える |
| 12世紀 | アラビア語（誤読） | jaib | **懐・湾** ❌ |
| 12世紀 | ラテン語 | sinus | **入り江** ❌ |
| 現代 | 英語・日本語 | sine / サイン | 意味不明のまま定着 |

**1000 年かけて、「弓の弦」が「入り江」になりました。**

> ⚠️ この経路は数学史でよく語られる定説ですが、
> 誰がいつ誤読したかの細部には諸説あり、確定していない部分もあると伝えられています。
> ただ「$\sin$ の語源が本来の意味とずれている」ことは広く受け入れられています。

## $\cos$ は「補角のサイン」

ついでに $\cos$ も解いておきましょう。こちらは誤訳ではありません。

**co-sine** の **co-** は「**complementary（補足の）**」の略です。

$$
\cos\theta = \sin(90° - \theta)
$$

「$90°$ から引いた角（補角, complementary angle）のサイン」だから **complementi sinus** → **cosine**。

同じ理屈で:

- **cotangent** = 補角の tangent
- **cosecant** = 補角の secant

$\cos$ の「co」が見えると、$\sin$ と $\cos$ の関係式が丸暗記でなくなります。

## 名前は間違ったが、中身は正しかった

ここが大事なところです。

名前は誤訳でも、**数学の中身は 1500 年間まったく壊れていません**。
インドの天文学者が計算した「半弦の表」は、今の $\sin$ の値と一致します。

```python
import numpy as np

# アーリヤバタたちが計算していたのは「半径 r の円の半弦の長さ」
r: float = 1.0                      # 半径 (単位円)
theta: float = np.pi / 6            # 30° をラジアンで (単位: rad)

half_chord: float = r * np.sin(theta)   # 半弦の長さ
print(f'半径 {r} の円、中心角 {np.degrees(2*theta):.0f}° の弦の半分 = {half_chord}')
# → 0.49999999999999994   (理論値 0.5)

# 現代の sin と、古代の「半弦」は同じもの
print(f'sin(30°) = {np.sin(np.pi/6):.4f}')
```

**記号や名前は人間の都合で揺れるが、数学的な内容は揺れない。**
これは記号を学ぶうえで、とても心強い事実です。

## 現代への接続 — 「弓の弦」は今、AI の中にいる

$\sin$ の応用先は、もはや天文学どころではありません。

| 分野 | どう使われるか |
|---|---|
| 音声・音楽 | 音は波。フーリエ変換で $\sin$ / $\cos$ の重ね合わせに分解する |
| 画像圧縮 | JPEG は画像を $\cos$ 波の重ね合わせで表す（離散コサイン変換, DCT） |
| 通信 | 電波の変調・復調 |
| 物理シミュレーション | 振動・波動・回転のすべて |
| **深層学習** | **Transformer の位置エンコーディング** |

最後のものが特に面白い。

ChatGPT や Claude のような大規模言語モデルの基礎である **Transformer** は、
単語の「順番」を伝えるために **$\sin$ と $\cos$ を使っています**。

$$
\begin{aligned}
PE(pos, 2i) &= \sin\left(\frac{pos}{10000^{2i/d}}\right) \\
PE(pos, 2i+1) &= \cos\left(\frac{pos}{10000^{2i/d}}\right)
\end{aligned}
$$

```python
import numpy as np

def positional_encoding(seq_len: int, d_model: int) -> np.ndarray:
    """Transformer の正弦波位置エンコーディングを作る.

    Args:
        seq_len: 系列長 (単語数)
        d_model: 埋め込みの次元数 (偶数)

    Returns:
        位置エンコーディング, shape: (seq_len, d_model)
    """
    pos = np.arange(seq_len)[:, None]              # shape: (seq_len, 1)
    i = np.arange(0, d_model, 2)[None, :]          # shape: (1, d_model/2)
    angle = pos / np.power(10000, i / d_model)     # shape: (seq_len, d_model/2)

    pe = np.zeros((seq_len, d_model))              # shape: (seq_len, d_model)
    pe[:, 0::2] = np.sin(angle)                    # 偶数番目は sin
    pe[:, 1::2] = np.cos(angle)                    # 奇数番目は cos
    return pe


pe = positional_encoding(seq_len=10, d_model=8)    # shape: (10, 8)
print(pe.shape)
print(np.round(pe[:3], 3))   # 最初の 3 単語ぶんの位置ベクトル
```

5 世紀のインドで**天体の位置**を計算するために生まれた「弓の弦」が、
21 世紀には**文中の単語の位置**を表すために使われている。

1500 年を隔てて、どちらも「**位置**を数で表す」という同じ仕事をしているわけです。

## まとめ

- $\sin$ の語源は「入り江」だが、**本来は「弓の弦」だった**
- サンスクリット → アラビア語 → ラテン語の 1000 年の伝言ゲームで、**母音の省略が誤読を生んだ**
- $\cos$ の **co-** は「補角の (complementary)」
- **名前は間違っても、数学の中身は壊れなかった**
- そして「弓の弦」は今、Transformer の中で単語の位置を運んでいる

記号や名前に納得がいかないとき、それは**あなたの理解不足ではなく、歴史の事故**かもしれません。
そう思えるだけで、少し気が楽になりませんか。
