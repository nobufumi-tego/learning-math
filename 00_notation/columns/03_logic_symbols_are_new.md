# コラム 03: `∀ ∃ ∈ ∅` は新参者 — 論理記号は、あなたのひいおじいさんと同世代

> *ピタゴラスの定理は 2500 年前。でも `∀` が生まれたのは 1935 年です。*

## 数学記号にも「生まれ年」がある

数学は古い学問です。ピタゴラスの定理は紀元前 6 世紀、ユークリッドの『原論』は紀元前 3 世紀。
$\pi$ の計算はアルキメデスが紀元前 3 世紀にやっています。

ところが、あなたが [`02_set_theory.md`](../02_set_theory.md) と [`03_logic_symbols.md`](../03_logic_symbols.md) で学んだ記号は、
**驚くほど新しい**のです。

| 記号 | 生まれた年（頃） | 誰が |
|---|---|---|
| $=$ | 1557 | ロバート・レコード |
| $\int$, $dx$ | 1675 | ライプニッツ |
| $\Sigma$ | 1755 | オイラー |
| $\in$ | **1889** | ペアノ |
| $\exists$ | **1897頃** | ペアノ |
| $\forall$ | **1935** | ゲンツェン |
| $\emptyset$ | **1939頃** | ブルバキ（アンドレ・ヴェイユ） |

$\forall$ は **1935 年**。第二次世界大戦の前です。
**あなたのひいおじいさん・ひいおばあさんが生きていた頃**に作られた記号だということです。

なぜこんなに新しいのでしょうか。

## 理由: 「集合」と「論理」を数学にしたのが最近だから

19 世紀の終わりまで、数学者は「集合」や「すべての〜が成り立つ」を
**普通の言葉で書いて**いました。記号にする必要を感じていなかったのです。

状況を変えたのは、19 世紀末に始まった **数学の基礎を厳密にしよう** という運動でした。

きっかけの一つは **ゲオルク・カントール (Georg Cantor)** です。
1874 年以降、彼は「無限」を正面から数学の対象にしました。
無限には**大きさの違いがある**（自然数の無限より実数の無限のほうが「大きい」）という主張は、
当時あまりに衝撃的で、激しい批判を浴びたと伝えられます。

無限のような繊細な対象を扱うには、**日常語では曖昧すぎました**。
「すべての」「ある〜が存在する」を、誤解の余地なく書き分ける記号が必要になったのです。

## ジュゼッペ・ペアノ — 記号を作りまくった人

イタリアの数学者 **ジュゼッペ・ペアノ (Giuseppe Peano, 1858-1932)** は、
数学を完全に記号だけで書き表そうと試みました。

1889 年の著書『算術原理 (Arithmetices principia)』で、彼は自然数の公理系（**ペアノの公理**）を
**ほぼ記号だけ**で記述してみせます。

このとき彼が導入した記号の一つが $\in$ です。

由来はギリシャ語の **ἐστί (esti)** — 英語の *is* にあたる語です。
その頭文字 **ε（イプシロン）** を使いました。

$$
x \in A \quad \text{←「} x \text{ は } A \text{ で*ある*」}
$$

つまり $\in$ は、もともと「**である**」という動詞だったのです。
だから $x \in A$ は記号の羅列ではなく、**一つの文**として読めます。

> 📌 今の $\in$ は $\varepsilon$ よりやや角ばった専用の字形になっていますが、
> 出自はギリシャ文字のイプシロンです。

ペアノは $\exists$（存在する）も導入したとされます。こちらは **E**xist の **E** を裏返した形。
$\cup$（和集合）、$\cap$（共通部分）もペアノの考案と伝えられます。

## $\forall$ は意外と遅かった

不思議なことに、$\exists$（存在する）のほうが $\forall$（すべての）より**先**に生まれています。

ラッセルとホワイトヘッドの『プリンキピア・マテマティカ』(1910-13) でも、
「すべての $x$ について」は $\forall x$ ではなく、単に **$(x)$** と括弧で書かれていました。

$\forall$ が登場するのは **1935 年**、ドイツの論理学者
**ゲルハルト・ゲンツェン (Gerhard Gentzen, 1909-1945)** の論文とされます。

由来は、ドイツ語の **Alle**（すべて）あるいは英語の **All** の **A を上下逆さま**にした形。

$$
\text{A} \;\to\; \forall
$$

$\exists$ が E の裏返し、$\forall$ が A の逆さま。**並べてみると発想が同じ**です。

> 📝 ゲンツェンは**自然演繹**と**シークエント計算**を作り上げた、証明論の巨人です。
> ただ、その生涯は時代に翻弄されました。第二次世界大戦末期にプラハで収監され、
> 1945 年に 35 歳で亡くなっています。
> $\forall$ という記号は、この短い生涯が残したものの一つです。

## $\emptyset$ はギリシャ文字ではない

最後に $\emptyset$（空集合）。

これを「ファイ（$\phi$）」と読む人が非常に多いのですが、**ギリシャ文字ではありません**。

$\emptyset$ は **ノルウェー語・デンマーク語のアルファベット「Ø」** です。
（ノルウェー語で `øl` はビール、`ø` は島を意味します。）

導入したのは **ニコラ・ブルバキ (Nicolas Bourbaki)**。

### ブルバキという「存在しない数学者」

ここも面白い話です。ニコラ・ブルバキは**実在しません**。

1930 年代のフランスで、若手数学者たちが「数学全体を厳密に書き直す」という
壮大なプロジェクトを始めました。アンドレ・ヴェイユ、アンリ・カルタン、ジャン・デュドネら。

彼らは**集団のペンネーム**として「ニコラ・ブルバキ」という架空の数学者を名乗りました。
（名前は実在の将軍シャルル・ブルバキから採ったと言われます。）

ブルバキ名義の著作は膨大な巻数にのぼり、20 世紀の数学の書き方そのものを変えました。

その中で、空集合の記号として **Ø** が採用されます。
メンバーの **アンドレ・ヴェイユ** が、ノルウェー語のアルファベットを知っていたので提案した、
と彼自身の回想に記されていると伝えられます。

> 💡 つまり $\emptyset$ は、**架空の数学者の名義で、北欧の文字が採用された記号**です。
> $\phi$ と読むのは、厳密には間違いということになります。

## 現代への接続 — 記号はコードになった

ペアノやゲンツェンが作った記号は、いま**プログラミング言語の中で動いています**。

| 論理記号 | 意味 | Python |
|---|---|---|
| $\forall x \in A: P(x)$ | すべての $x$ で $P$ が成立 | `all(P(x) for x in A)` |
| $\exists x \in A: P(x)$ | ある $x$ で $P$ が成立 | `any(P(x) for x in A)` |
| $x \in A$ | 属する | `x in A` |
| $\emptyset$ | 空集合 | `set()` |
| $A \cup B$ | 和集合 | `A \| B` |
| $A \cap B$ | 共通部分 | `A & B` |

```python
A: set[int] = {1, 2, 3, 4, 5, 6}

# ∀x ∈ A: x > 0   「A のすべての要素は正である」
print(all(x > 0 for x in A))      # → True

# ∃x ∈ A: x > 5   「A に 5 より大きい要素が存在する」
print(any(x > 5 for x in A))      # → True

# ∈ はそのまま in
print(3 in A)                     # → True

# ∅ は空集合。要素が 0 個
empty: set[int] = set()           # ← {} は空の辞書なので注意
print(len(empty), empty == set()) # → 0 True
```

Python の `all()` / `any()` は、$\forall$ / $\exists$ そのものです。
**1889 年のペアノの記号が、そのまま関数名になっている**と言ってもいい。

SQL にも `EXISTS` があり、これは $\exists$ です。
型システムや形式検証の世界では、$\forall$ が「ジェネリクス」として現れます
（Python の `TypeVar`、Rust や Haskell の型変数は「すべての型 T について」の意味です）。

```python
from typing import TypeVar

T = TypeVar('T')   # ∀T  「すべての型 T について」

def first(items: list[T]) -> T:
    """リストの先頭を返す (どんな型のリストでも動く).

    Args:
        items: 任意の型 T の要素からなるリスト

    Returns:
        先頭の要素
    """
    return items[0]
```

この `TypeVar` の宣言は、論理学の記法で書けば $\forall T$ です。
**ゲンツェンの記号が、型システムの中で生きている**わけです。

## まとめ — 記号が新しいということの意味

- $\in$ は 1889 年、$\forall$ は 1935 年。**論理記号は 100 年ちょっとの新参者**
- 理由は、**数学が「厳密さ」を求め始めたのが 19 世紀末だったから**
- $\in$ はギリシャ語の「である」、$\exists$ は E の裏返し、$\forall$ は A の逆さま
- $\emptyset$ はギリシャ文字 $\phi$ ではなく、**ノルウェー語の Ø**
- これらは今、`all()` / `any()` / `in` / `set()` としてコードの中で動いている

そして、もう一つ。

> **記号が新しいということは、まだ「決着していない」ということでもあります。**

実際、$\subset$ を「真部分集合」の意味で使う人と「部分集合（等しい場合を含む）」で使う人がいて、
現在も混在しています。教科書の最初のページに「本書では $\subset$ を〜の意味で使う」と
断り書きがあるのは、そのためです。

記号は完成された体系ではなく、**今も人間が使いながら調整している道具**なのです。
