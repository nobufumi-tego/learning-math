# コラム 00: 等号 `=` の誕生 — 「2本の平行線ほど、等しいものはない」

> *人類が「イコール」を発明したのは、たった 470 年ほど前のことです。*

## 記号がなかった時代の数学

いきなりですが、次の式を「記号を一切使わずに」書いてみてください。

$$
14x + 15 = 71
$$

16 世紀のヨーロッパの数学者は、実際にこう書いていました。

> **14 のプラスの数と 15 とを合わせたものは、71 に等しくなる**

これでもまだ短いほうです。当時のラテン語やイタリア語の数学書では、
「等しい」を意味する言葉を **毎回そのまま単語で書いていました**。

- ラテン語なら `aequales`, `aequantur`
- 英語なら `is equalle to`
- イタリア語なら `fa`（「〜になる」）

計算の途中式が 10 行あれば、`is equalle to` を **10 回書く**わけです。

> 💡 想像してみてください。プログラミングで `=` の代わりに毎回
> `is_assigned_the_value_of` と打つとしたら。1 日で嫌になりますよね。
> 16 世紀の数学者は、それを一生やっていました。

## ロバート・レコードという人

この状況を変えたのが、ウェールズ生まれの医師 **ロバート・レコード (Robert Recorde, 1512頃-1558)** です。

彼は少し変わった経歴の持ち主でした。

- オックスフォードとケンブリッジで学び、**医師**の資格を取る
- 一方で数学書を書き、**英語で**数学を教えることに情熱を注いだ
- 王室の**造幣局監督**やアイルランドの鉱山監督も務めた
- 最後は有力貴族との訴訟に敗れ、**借金のため獄中で死去**したと伝えられる

当時の学術書はラテン語で書くのが常識でした。ラテン語が読めない一般の人は、
数学を学ぶことすらできなかったのです。

レコードはそこに反発しました。**「数学は英語で書かれるべきだ」**。
彼の著書は対話形式（先生と生徒の問答）で書かれ、初学者が読めるよう工夫されています。

> 📌 「専門家しか読めない言葉で書かれた知識は、社会を変えられない」
> — これは 500 年前の問題であり、今もそのまま生きているテーマです。
> このリポジトリが日本語で書かれているのも、同じ発想の延長にあります。

## 1557年、記号が生まれた瞬間

レコードの著書 **『知恵の砥石 (The Whetstone of Witte)』** (1557年) に、
数学史に残る一文が登場します。

彼はこう書きました（現代英語に直した意訳）:

> **「同じことを何度も『〜に等しい』と書くのが面倒なので、
> 私はよく使う記号として、長さの等しい 2 本の平行線を使うことにした。
> なぜなら、2 つのものでこれ以上に等しいものは、ありえないからだ。」**

これが **`=` の誕生**です。

理由が美しいと思いませんか。

> **「2 本の平行線ほど、互いに等しいものはない」**

平行線はどこまで伸ばしても間隔が変わりません。永遠に等しい。
だから「等しい」の記号にふさわしい。

記号の形に、**意味がちゃんと込められている**のです。

### ただし、当時の `=` はもっと長かった

レコードが実際に書いた記号は、今よりずっと長い平行線でした。

```
14.ʒ.——+.15.ʒ.————— 71.ʒ.
                ═══════
```

イメージとしては `═══════` くらいの長さ。
印刷技術の都合で、だんだん短くなって今の `=` に落ち着きました。

## すぐには広まらなかった

ここが面白いところなのですが、**`=` はすぐには普及しませんでした**。

| 年 | 出来事 |
|---|---|
| 1557 | レコードが `=` を考案 |
| 1600年代前半 | ほとんど使われず。多くの数学者は今まで通り単語で書き続けた |
| 1631 | トーマス・ハリオットとウィリアム・オートレッドの著書で使われ、じわじわ広まる |
| 1637 | **デカルトは `=` を使わず**、別の記号（`∝` に似た形）を採用 |
| 1700年頃 | ようやくヨーロッパの標準になる |

**普及まで約 150 年**。

デカルトほどの大数学者が別の記号を推していたことも、混乱の一因でした。
もしデカルト派が勝っていたら、私たちは今ごろ別の記号で計算していたかもしれません。

> 💡 **良い記号でも、広まるには時間がかかる。**
> これはプログラミング言語や記法の歴史とまったく同じ構図です。

## 現代への接続 — `=` と `==` の混乱

さて、この話には現代的な続きがあります。

数学の `=` は「**左右は等しい**」という**主張**です。

$$
x = 5 \quad \text{← 「} x \text{ は 5 に等しい」という事実の宣言}
$$

ところが Python では:

```python
x = 5        # 代入: 「x に 5 を入れる」という命令
x == 5       # 比較: 「x は 5 と等しいか?」という質問
```

**同じ `=` が、数学とプログラミングで別の意味を持っています。**

なぜこうなったかというと、初期のプログラミング言語が「代入」に `=` を借用したからです。
数学的にはやや乱暴で、実際こんな式が書けてしまいます:

```python
x = x + 1    # 数学的には「x = x + 1」→ 0 = 1 という矛盾!
             # でもプログラムとしては「x を 1 増やす」で正しい
```

この違和感を嫌って、代入に `:=` を使う言語もあります（Pascal, Go の一部, そして Python 3.8 以降のウォルラス演算子）。

```python
# Python 3.8+ のウォルラス演算子
if (n := len(data)) > 10:
    print(f'{n} 件は多すぎます')
```

数学で「定義する」を意味する `:=` が、プログラミングに逆輸入されてきた形です。

> 📌 **記号の意味は文脈で変わる**、という [`07_decorations_and_fonts.md`](../07_decorations_and_fonts.md) のテーマが、
> ここでも顔を出しています。$=$ ですら一枚岩ではないのです。

## まとめ — 記号は「発明品」である

私たちは $=$ を空気のように使っています。でも:

- 誰かが**発明**しなければ、存在しなかった
- 発明されても、**広まるまで 150 年**かかった
- 形には**理由**があった（平行線 = 永遠に等しい）
- 今も**意味は揺れている**（数学の等号 vs プログラムの代入）

記号は天から降ってきたものではなく、**人間が不便を感じて作った道具**です。
そう思うと、少しだけ親しみが湧いてこないでしょうか。

次にあなたが `=` をタイプするとき、
獄中で生涯を終えたウェールズの医師のことを、少しだけ思い出してください。
